# TDD в ArtHello OS

По мотивам /tdd с aihero.dev, настроено под тестовую инфраструктуру проекта.

## Инфраструктура (не выдумывать другую)

- Раннер: **`node --test`**, файлы `*.test.mjs`. Vitest/jest в проекте нет — не добавлять.
- Расположение: `artifacts/api-server/test/`, `artifacts/alpha-crm-sync/test/`, `scripts/test/`, `sites-control/tests/`.
- БД-логика: **PGlite** (in-process Postgres) — образец: `scripts/test/alfacrm-snapshot-pglite.test.mjs`, хелпер `scripts/test/alfacrm-test-db.mjs`. Интеграция с реальным PG16 — `artifacts/api-server/test/postgres.integration.test.mjs`, требует `TEST_DATABASE_URL` (без него честно падает — не маскировать skip'ом молча).
- Запуск: `pnpm run test:security`, `test:front-office`, `test:postgres`, `test:full`. Помни: `test:full` НЕ включает `test:postgres` и suite `scripts/` — если твои тесты там, запускай их явно и говори об этом.

## Цикл

1. **Red**: напиши падающий тест на поведение (вход → наблюдаемый результат). Запусти, убедись что падает **по ожидаемой причине** (не из-за опечатки), процитируй вывод.
2. **Green**: минимальная реализация до зелёного. Не рефактори параллельно.
3. **Refactor**: чистка под зелёными тестами. Затем `pnpm run typecheck`.

## Правила проекта

- **Тест = поведение, не текст.** Regex/`readFile`-ассерты по исходникам («в файле есть строка requireAuth») — легитимный приём только для анти-дрейф рачетов безопасности (образец: `sites-control/tests/security-regression.test.mjs`), но **не считается тестом новой логики**. Новая логика проверяется исполнением.
- **Финансовые расчёты**: только синтетические инварианты без реальных ставок/KPI (D-030) — целочисленные minor units, балансовые тождества, reversals, rounding. Реальные ставки в тестах запрещены до утверждения владельцем.
- **Identity-логика** (normalizePhone и родня): characterization-тесты на все известные входные формы; в проекте 3–4 расходящихся варианта — при касании зафиксируй текущее поведение каждого до объединения.
- **Fail-closed по умолчанию**: негативные тесты (deny, отсутствие env, ошибка миграции) не менее важны позитивных — образец: `security.test.mjs`.
- Тестовые данные — синтетические. Реальные PII/выгрузки в тестах запрещены.

## Отчёт

В конце: какие тесты добавлены (пути), красный вывод → зелёный вывод (цитаты), какие агрегатные скрипты их подхватывают, а какие нет.
