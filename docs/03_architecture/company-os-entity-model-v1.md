# Company OS Universal Entity Model v1.0

Полная универсальная модель является целевой смысловой архитектурой для текущих и будущих проектов. Отдельный проект не имеет права урезать или переписывать её под себя. Для MVP используется минимальное ядро, а отраслевые объекты добавляются как расширения.

## Базовый класс `Entity`

Каждая сущность имеет устойчивую идентичность, проектную область, тип, владельца, версию и аудит.

Обязательное разделение:

- `status` — деловое состояние объекта;
- `lifecycle_state` — техническое состояние жизненного цикла.

Удаление не переписывает историю. Значимые изменения создают `Audit Event` и при необходимости `Change Request`.

## `Relationship`

`Relationship` — самостоятельная сущность графа, а не скрытый join без смысла.

Она фиксирует:

- тип связи;
- источник и доказательство;
- направление;
- дату начала и окончания;
- статус;
- уверенность;
- автора подтверждения;
- историю изменения.

Связь не считается фактом только потому, что совпали телефон, фамилия или сумма.

## Правило расширения

Отраслевая сущность:

1. расширяет универсальную модель;
2. не заменяет базовые сущности;
3. имеет источник истины;
4. имеет связи через `Relationship`;
5. сохраняет проектную изоляцию;
6. получает аудит и правила доступа.

Полный архивный перечень всех не-MVP сущностей универсальной модели в доступных источниках не найден. Поэтому этот документ фиксирует подтверждённое ядро без выдуманного дополнения; дальнейшее расширение проходит отдельное утверждение.
