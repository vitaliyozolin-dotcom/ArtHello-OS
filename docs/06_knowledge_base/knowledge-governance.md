# Управление базой знаний

## Жизненный цикл

`DRAFT → REVIEW → APPROVED → EFFECTIVE → EXPIRED / REVOKED`

Утверждённая версия неизменяема. Исправление создаёт новую версию.

## Статусы достоверности

- `VERIFIED` — подтверждено актуальным источником.
- `PARTIAL` — источник есть, но контекст неполон.
- `UNVERIFIED` — подтверждения нет.
- `CONFLICT` — источники расходятся.
- `STALE` — источник устарел.

Фактический ответ AI использует только `VERIFIED`. `PARTIAL` допустим в черновике с явным указанием нехватки. Остальные статусы блокируют уверенный ответ.

## Обязательные поля знания

- проект;
- тема;
- филиалы и услуги;
- аудитория;
- владелец;
- утверждающий;
- источник;
- дата вступления;
- дата следующей проверки;
- исключения;
- разрешённые действия;
- обязательная эскалация;
- шаблон ответа;
- версия.

## Claim-level provenance

Существенное утверждение связывается с:

- `fact_id`;
- версией;
- источником;
- датой актуальности;
- областью применения;
- статусом достоверности.

## Knowledge gap

Создаётся, если:

- вопрос повторяется;
- статьи нет;
- источники конфликтуют;
- политика устарела;
- сотрудник сообщил новое правило только в переписке;
- выявлено исключение.

Сообщение сотрудника, правка черновика или AI-текст являются только кандидатом. Автоматическая публикация запрещена.
