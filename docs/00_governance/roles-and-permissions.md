# Роли и права

## Предлагаемые роли

- собственник;
- руководитель ArtHello;
- руководитель филиала;
- оператор продаж;
- оператор сервиса;
- педагог;
- финансист;
- редактор знаний;
- утверждающий знаний;
- маркетинговый аналитик;
- QA read-only;
- системный администратор;
- ответственный за безопасность;
- ответственный за персональные данные;
- юридический ответственный.

Назначения конкретных людей пока не утверждены.

## Разделение полномочий

- Оператор не утверждает знания.
- Редактор не публикует собственную критичную статью без второго просмотра.
- Маркетинг не читает тела личных диалогов.
- QA получает минимизированные данные.
- Системный администратор не заменяет бизнес-утверждающего.
- Права на ребёнка, финансы и договоры выдаются отдельно.
- Интерфейсное скрытие кнопки не заменяет серверную проверку.
- Чтение чувствительных данных журналируется.

## Высокорисковые операции

Требуют усиленной проверки и человека:

- возврат;
- смена плательщика;
- изменение существенных условий;
- получение ребёнка другим человеком;
- смена подтверждённого представителя;
- выгрузка большого объёма персональных данных.
