# Идентификация и конфиденциальность семьи

## Без проверки личности

Разрешена только общая публичная информация:

- направления;
- публичные цены и условия из актуального источника;
- формат;
- публичные ссылки;
- первичный запрос.

## Стандартная проверка

Требуется перед раскрытием:

- расписания конкретного ребёнка;
- договора семьи;
- начислений и оплат;
- посещаемости;
- истории обращений;
- документов;
- данных бронирования занятия.

Используется только утверждённый процесс. Самодельные «секретные вопросы» запрещены.

## Усиленная проверка и человек

- изменение плательщика;
- возврат;
- изменение договора;
- передача ребёнка другому человеку;
- смена владельца профиля;
- большой объём персональных данных.

## Семейная модель

- CRM-клиент не равен семье.
- Плательщик не равен законному представителю.
- Родственник не получает доступ на основании фамилии.
- Один родитель не получает сведения другого без подтверждённых прав.
- Информация о другом ребёнке не раскрывается.
- Долг не обсуждается с ребёнком.
- Семьи не объединяются автоматически.

Полная `IDENTITY_VERIFICATION_POLICY` и `DATA_RETENTION_POLICY` ещё требуют утверждения.
