# Граница проекта

## Включено

ArtHello OS обслуживает операционный, финансовый, управленческий, продажный и сервисный контур проекта `ARTHELLO`.

## Исключено

«Школа 1–11» является отдельным контуром:

- отдельное юридическое лицо;
- отдельные данные;
- отдельная очередь;
- отдельная база знаний;
- отдельные права;
- отдельная аналитика;
- отдельные клиентские каналы.

До утверждения явной интеграционной связи совпадение фамилии, телефона, ребёнка, представителя, сотрудника или суммы не является основанием для объединения.

## Запреты

- Глобальный поиск клиентов по нескольким проектам.
- Перенос документов и политик между проектами без отдельного решения.
- Смешанная аналитика.
- Общий журнал клиентских сообщений.
- Автоматическое объединение профилей.
- Использование знаний другого проекта для ответа ArtHello.

## Проектный ключ

На каждом чувствительном агрегате обязателен `project_id = ARTHELLO`. Проект определяется из авторизованного контекста, а не принимается как доверенное поле клиентского запроса.
