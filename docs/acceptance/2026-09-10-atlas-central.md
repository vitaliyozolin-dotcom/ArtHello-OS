# Центральный вход в дневник Атласа — кандидат D109

База: fdb93556bf3cff27849a872c3f3bba1ae712364b. Связанный дневник: PR411, отдельная ветка atlas/foundation. Production не изменён.

Реализованы отдельные open/authorize/exchange/check API, назначение Atlas system grant, роли директора/завуча/методиста/учителя/администратора, раздельные кнопки дневников. Check — только подписанный server-to-server запрос ограниченного размера, 60 секунд допустимого времени, отдельный секрет и институциональные идентификаторы. Проверяется активность учётной записи, обеих систем, филиала, роль и версия.

Проверки: production build, TypeScript, targeted ESLint — PASS. Два изолированных Miniflare HTTP-сценария SSO (Атлас и прежний «1–11») — PASS: обычный вход, смена временного пароля, явная выдача/отзыв, PKCE/replay, блокировка/роль/версия, отделение школы/садика, неверная подпись.

Полный локальный suite: 797 тестов, 788 PASS, 2 skipped, 7 failed. Один source contract относится к намеренно переименованной кнопке; обновлён по D109 и перепроверяется. Шесть тестов банковского activation marker не могут выполнить chown на UID 1002 в данном окружении (EINVAL); код банка не изменён, финальное подтверждение — hosted CI.

Нужны exact-source hosted CI, production deployment центрального runtime по действующему защищённому протоколу, отдельные Atlas сервис/тома/секрет/маршрут и обычный браузерный проход. Персональные права и реальные школьные данные не изменены. Проекция семей в Атлас центральным интерфейсом пока не подключена.
