# Возврат из дневника в ArtHello OS

Основание: поручение Виталия, существующее обращение в OS; решение D-SCHOOL-RETURN-001. База School: 54242340f2d9b6a9887d69ecc03520ddf9f7982c.

Общий School shell показывает сотрудникам текстовую ссылку над верхней панелью. Родители и ученики сохраняют прежний интерфейс. Ссылка является обычным anchor, не logout и не history.back. Сервер направляет только на корень существующего проверенного ARTHELLO_PUBLIC_ORIGIN; query/referrer не используются. Auth, права, БД, cookie и PKCE flow не меняются. При неправильной конфигурации возвращается текстовая 503 без утечки конфигурации.

Локальная проверка фактической функции arthelloOrigin и GET на Node 24.19 с удалением TypeScript-аннотаций: 2 корректных адреса (настроенный и штатный) дают 303, Set-Cookie отсутствует; 4 неправильных origin (HTTP в production, credentials, path, javascript) дают 503 без Location. Адрес запроса и returnTo игнорируются. CSS использует существующие токены, активная зона минимум 44px, текст переносится. Это не визуальный PASS.

Открыто: полная сборка; семь контрольных ширин, keyboard и 200% zoom; проверки ролей; живой цикл ArtHello → School → ArtHello с действующей и истёкшей OS-сессией. Не заявлять production acceptance по одному source test. Выпускать отдельный точный School image после завершения активного банковского выпуска и проверки School identity/backup/rollback. Main и работающий School этой веткой не изменены.
