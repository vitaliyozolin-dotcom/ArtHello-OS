# Архив

Сюда переносятся:

- заменённые документы;
- устаревшие политики;
- исторические snapshots;
- материалы, утратившие операционную силу.

Архивный документ:

- не удаляется;
- сохраняет источник и версию;
- получает ссылку на заменивший документ;
- не используется AI как действующий факт.
