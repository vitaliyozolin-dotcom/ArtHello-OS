## Правила

- AlfaCRM-клиент не считается автоматически семьёй.
- CRM-начисление не равно банковскому поступлению.
- Договор не равен оплате.
- Скриншот не заменяет системный статус.
- Внешняя запись уникальна по `project + source + entity_type + external_id`.
- Конфликт сохраняется как `SourceConflict`, а не разрешается молча.
- Публичный сайт не отменяет индивидуальный договор.
