# Таксономия обращений ArtHello

Таксономия используется для маршрутизации, аналитики, SLA, тестов и выбора
допустимого действия. Один диалог может содержать несколько intent.

## Публичная информация

| Код | Содержание | Личность | Базовый приоритет |
|---|---|---|---|
| `INFO.PROGRAM` | Направления и содержание программы | Не требуется | P4 |
| `INFO.AGE` | Возрастные границы | Не требуется | P4 |
| `INFO.BRANCH` | Филиал, адрес, навигация | Не требуется | P4 |
| `INFO.SCHEDULE_PUBLIC` | Публичное расписание | Не требуется | P4 |
| `INFO.PRICE_PUBLIC` | Действующая публичная цена | Не требуется | P4 |
| `INFO.TRIAL` | Формат пробного занятия | Не требуется | P4 |
| `INFO.AVAILABILITY` | Наличие мест | Не требуется, если ответ обезличен | P4 |
| `INFO.DOCUMENTS` | Общий список документов | Не требуется | P4 |
| `INFO.VISIT_RULES` | Общие правила посещения | Не требуется | P4 |

Автоматический фактический ответ допустим только при статусе факта
`VERIFIED` и разрешённом режиме. Пока внешняя отправка отключена, создаётся
только черновик.

## Лид и подбор

| Код | Содержание | Минимальные данные | Риск |
|---|---|---|---|
| `LEAD.NEW` | Первичное обращение | Контакт в разрешённом канале | Низкий |
| `LEAD.QUALIFY` | Возраст, район, цель, время, формат | Минимум для подбора | Низкий |
| `LEAD.PROGRAM_MATCH` | До двух подходящих программ | Проверенный каталог | Средний |
| `LEAD.TRIAL_REQUEST` | Запрос пробного занятия | Программа, филиал, время | Средний |
| `LEAD.TRIAL_STATUS` | Статус заявки на пробное | Проверка личности при непубличных данных | Средний |
| `LEAD.FOLLOW_UP` | Следующий контакт | Согласованный канал и цель | Низкий |
| `LEAD.LOST` | Причина потери | Подтверждённая причина | Низкий |

AI не ставит диагноз, не обещает образовательный результат и не создаёт
ложный дефицит.

## Действующая семья

| Код | Содержание | Проверка | Базовый приоритет |
|---|---|---|---|
| `FAMILY.SCHEDULE` | Расписание конкретного ребёнка | Стандартная | P3 |
| `FAMILY.GROUP` | Группа ребёнка | Стандартная | P3 |
| `FAMILY.ATTENDANCE` | Посещаемость | Стандартная | P3 |
| `FAMILY.MISSED_CLASS` | Пропуск и отработка | Стандартная | P3 |
| `FAMILY.FREEZE` | Заморозка | Стандартная + политика | P3/P2 |
| `FAMILY.SUBSCRIPTION` | Абонемент | Стандартная | P3 |
| `FAMILY.CHANGE_CONTACT` | Изменение контакта | Стандартная или усиленная | P2/P3 |
| `FAMILY.PICKUP_PERSON` | Получение ребёнка другим лицом | Усиленная + человек | P1/P2 |
| `FAMILY.DOCUMENT_COPY` | Документы семьи | Стандартная | P3 |

## Образовательный процесс

| Код | Содержание | Действие |
|---|---|---|
| `EDU.ADAPTATION` | Адаптация ребёнка | Собрать факты, передать педагогу |
| `EDU.PROGRESS` | Обратная связь о прогрессе | Передать педагогу/руководителю |
| `EDU.PROGRAM_DIFFICULTY` | Сложность программы | Не интерпретировать состояние ребёнка |
| `EDU.BEHAVIOR` | Поведение | Не ставить диагноз и не создавать ярлык |
| `EDU.GROUP_RELATION` | Отношения в группе | Не раскрывать данные других детей |
| `EDU.CONFLICT` | Конфликт детей | Человек; при угрозе — P0 |
| `EDU.SPECIAL_NEED` | Сообщённая родителем потребность | Минимум данных, доступ по роли |

## Финансы и договор

| Код | Содержание | Приоритет | Маршрут |
|---|---|---|---|
| `FIN.CHARGE` | Начисление | P3/P2 при споре | Финансы |
| `FIN.PAYMENT_STATUS` | Статус оплаты | P3/P1 при критической ошибке | Проверка CRM и банка |
| `FIN.DEBT` | Долг | P3 | Только уполномоченному лицу |
| `FIN.REFUND` | Возврат | P2 | Всегда человек |
| `FIN.DISCOUNT` | Скидка | P2/P3 | Только утверждённая программа |
| `FIN.COMPENSATION` | Компенсация | P2 | Всегда человек вне матрицы |
| `CONTRACT.CHANGE` | Существенное изменение договора | P2 | Усиленная проверка и человек |
| `CONTRACT.TERMINATION` | Расторжение | P2 | Всегда человек |

Начисление AlfaCRM, движение банка и юридический факт не взаимозаменяемы.

## Жалобы и удержание

| Код | Содержание | Приоритет | Маршрут |
|---|---|---|---|
| `COMPLAINT.CLASS_QUALITY` | Качество занятия | P2 | Руководитель |
| `COMPLAINT.TEACHER` | Жалоба на педагога | P2 | Всегда человек |
| `COMPLAINT.CANCELLATION` | Отмена/замена | P2/P3 | Администратор |
| `COMPLAINT.COMMUNICATION` | Коммуникация | P2/P3 | Руководитель сервиса |
| `COMPLAINT.SANITARY` | Санитарное состояние | P2/P0 при опасности | Руководитель |
| `COMPLAINT.FOOD` | Питание | P2 | Руководитель |
| `COMPLAINT.LOST_ITEM` | Утрата вещи | P3/P2 | Администратор |
| `RETENTION.FREEZE` | Риск ухода через заморозку | P2 | Ответственный за семью |
| `RETENTION.TERMINATION` | Намерение расторгнуть договор | P2 | Руководитель |
| `RETENTION.REPEAT_COMPLAINT` | Повторная жалоба | P2 | Руководитель |

Скидка не предлагается автоматически как способ удержания.

## Безопасность и критические случаи

Все intent ниже — `P0`, режим `incident`, немедленная передача человеку:

- `SAFETY.MISSING_CHILD`;
- `SAFETY.UNAUTHORIZED_PICKUP`;
- `SAFETY.INJURY`;
- `SAFETY.VIOLENCE`;
- `SAFETY.HARASSMENT`;
- `SAFETY.THREAT`;
- `SAFETY.SEVERE_CONFLICT`;
- `SAFETY.SUSPECTED_ABUSE`;
- `SAFETY.CHILD_DATA_LEAK`;
- `SAFETY.BUILDING_EMERGENCY`.

AI подтверждает получение и активирует утверждённый playbook, но не ведёт
расследование в чате и не обсуждает других детей.

## Персональные данные и безопасность аккаунта

- `PRIVACY.DATA_EXPORT`;
- `PRIVACY.DATA_CORRECTION`;
- `PRIVACY.DATA_DELETION`;
- `PRIVACY.CONSENT_WITHDRAWAL`;
- `PRIVACY.PROCESSING_EXPLANATION`;
- `PRIVACY.CHILD_OR_GUEST_DATA`;
- `PRIVACY.CALL_RECORDING`;
- `SECURITY.SOCIAL_ENGINEERING`;
- `SECURITY.WRONG_PROFILE`;
- `SECURITY.CROSS_PROJECT`.

Эти обращения не исполняются обычным ответом. Нужны проверка личности,
специальный тикет и назначенный ответственный.
