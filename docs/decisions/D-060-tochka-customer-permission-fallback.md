# D-060 — Не требовать ReadCustomerData для банковской интеграции Точки

Дата: 2026-09-03

## Решение

`GET /uapi/open-banking/v1.0/customers` больше не является обязательным доказательством работоспособности ключа Точки. Если каталог компаний отвечает `403`, ArtHello OS продолжает проверку через `GET /uapi/open-banking/v1.0/accounts` и использует `customerCode`, возвращённый в данных счёта, для безопасной привязки к выбранному юридическому лицу.

## Fail-closed границы

- `401` остаётся отказом ключа.
- `403` на `/accounts` остаётся точной ошибкой отсутствия права чтения счетов.
- Если `/customers` запрещён и счета не содержат `customerCode`, автоматическая привязка запрещена.
- Если счета принадлежат нескольким `customerCode`, требуется явный выбор одной компании.
- Выписки и операции загружаются только по счетам выбранного `customerCode`.
- Создание, подписание, отправка и отзыв платежей не разрешаются и не добавляются.

## Причина

Практический ключ собственника может иметь необходимые права чтения счетов и выписок без отдельного права чтения каталога компаний. Предыдущая реализация ошибочно делала `/customers` обязательным первым gate и поэтому отклоняла рабочий банковский ключ ещё до проверки счетов.
