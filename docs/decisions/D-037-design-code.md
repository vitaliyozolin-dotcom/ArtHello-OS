# D-037 — ArtHello OS Design Code 1.0 является обязательным стандартом

**Дата:** 2026-08-27  
**Статус:** принято владельцем  
**Нормативный документ:** [`DESIGN_CODE.md`](../../DESIGN_CODE.md)

## Решение

Вся ArtHello OS переводится на единый Design Code 1.0.

Единственными визуальными эталонами считаются:

- раздел «Доступы» — десктопная типографика, плотность и дисциплина;
- раздел «Обучение» — мобильные отступы, ритм, геометрия и читаемость;
- фирменная фиолетовая палитра ArtHello — цветовая идентичность.

Любой новый или изменяемый экран обязан использовать общие токены, компоненты и адаптивные правила из `DESIGN_CODE.md`.

## Запрещено

- добавлять новые последовательные mobile/CSS-слои;
- исправлять production очередным CSS append;
- использовать массовый `!important`;
- применять селекторы `[class*=card]`, `[class*=empty]`, `[class*=panel]`;
- создавать разные версии одинакового компонента в разных разделах;
- считать автоматические тесты визуальной приёмкой;
- принимать мобильный экран, являющийся механически сжатой десктопной версией.

## Обязательный подход

Работа выполняется компонентно:

1. токены и контейнер страницы;
2. Card, KpiCard и EmptyState;
3. SearchField, Tabs и PeriodSelector;
4. Modal/BottomSheet и система помощи;
5. перенос разделов на общие компоненты;
6. визуальная проверка на обязательных разрешениях;
7. только после этого — production cutover.

## Последствия

- локальные визуальные патчи, противоречащие Design Code, подлежат удалению;
- исправление общего компонента должно исправлять все разделы, где он используется;
- любое исключение требует отдельного зафиксированного решения владельца;
- критерий завершённости включает реальную визуальную проверку production-ссылки.
