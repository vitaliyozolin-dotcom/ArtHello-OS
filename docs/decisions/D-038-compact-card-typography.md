# D-038 — Компактная типографика «Доступов» является системным эталоном

**Дата:** 2026-08-28  
**Статус:** принято владельцем  
**Нормативный документ:** [`DESIGN_CODE.md`](../../DESIGN_CODE.md)

## Решение

Компактные карточки раздела «Доступы» утверждены как эталон одинаковых смысловых ролей ArtHello OS:

- заголовок — `12 / 15px`, вес `500`;
- краткое пояснение — `10 / 14px`, вес `400`;
- порядковый номер — `9 / 12px`, вес `800`.

Шкала реализуется общими токенами, компонентом `CompactListCard` и режимом `EmptyState density="compact"`.

## Область применения

Правило обязательно для компактных инструкций, карточных строк и встроенных пустых состояний рабочего блока во всех модулях, подчинённых общему ArtHello OS Design Code.

Правило не применяется к основному тексту страницы, обычным заголовкам, KPI, таблицам, кнопкам, поиску, формам, вкладкам, модальным окнам и полноэкранным состояниям.

Отдельный School 1–11 Design Code сохраняет приоритет внутри своей области.

## Последствия

- одинаковая смысловая роль имеет одну типографическую шкалу во всех модулях;
- локальные значения для этой роли удаляются;
- массовое уменьшение всего текста карточки запрещено;
- визуальная приёмка сравнивает computed styles с эталоном «Доступов».
