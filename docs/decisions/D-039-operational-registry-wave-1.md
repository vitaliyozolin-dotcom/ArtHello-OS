# D-039 — Компактные KPI операционных реестров являются системной ролью

**Дата:** 2026-08-28  
**Статус:** принято владельцем  
**Нормативный документ:** [`DESIGN_CODE.md`](../../DESIGN_CODE.md)

## Решение

Утверждённая KPI-сетка раздела «Подрядчики» становится эталоном для операционных реестров ArtHello OS: юридического контура, бухгалтерии и следующих мигрируемых разделов.

Геометрия, интервалы и типографика задаются семантическими токенами `--ah-registry-kpi-*`. Существующие токены `--ah-mobile-kpi-*` не переопределяются: они относятся к другому визуальному паттерну.

Первая плановая волна переводит юридический контур и бухгалтерию поверх утверждённого фундамента Design System. Production не переключается до отдельной зелёной визуальной приёмки.

## Область применения

Решение действует для плотной KPI-сетки рабочего реестра. Оно не применяется к KPI Главной и к продуктам с отдельным утверждённым дизайн-кодом, включая «Школу 1–11».

## Последствия

- локальные копии размеров KPI удаляются;
- одинаковые KPI-роли в мигрируемых реестрах используют одни токены;
- visual gate проверяет desktop и mobile computed styles;
- production переключается только после зелёной визуальной приёмки.
