# История изменений

## 2026-09-03

- главная стала плотной 12-колоночной доской: компактные блоки занимают одну треть строки, их можно перетаскивать и сохранять отдельно для каждого пользователя и роли;
- полностью удалены знаки вопроса и полевые маркеры подсказок, включая старые production-патчи, которые могли вернуть их после сборки;
- карточки пользователей уплотнены; должность задаётся вручную, шаблон роли предлагает стартовые права, а доступ к каждому разделу затем редактируется отдельной галочкой;
- «Интеграции», «Доступы» и «Проверка системы» собраны в Настройках; состав и порядок Избранного сохраняется персонально;
- собственник получил явную настройку отдельного входа в дневник без автоматической выдачи прав при открытии страницы; возврат за reverse proxy закреплён за внешним HTTPS-адресом, чтобы вход не уходил на внутренний HTTP;
- окна интеграций перенесены в верхний слой интерфейса, получили редактируемые формы, управление фокусом и рабочие действия с серверной проверкой прав и CSRF;
- банковская карточка Альфа-Банка заменена Т‑Банком по официальной H2H-инструкции; разрешены только проверки GET счетов v4 и короткой выписки v1, а подключение закрыто до подтверждения исходящего IP и минимальных прав токена;
- выбор компании Точки переведён на одноразовую серверную привязку, чтобы изменение порядка ответа банка не могло связать ключ с другим юрлицом;
- генератор изображений в «Контенте» возвращён на общую дизайн-систему;
- задачи, договоры, документы и связанные записи показывают понятные номера и подписи вместо внутренних буквенно-цифровых ключей;
- в договорах добавлены загрузка PDF/JPEG/PNG, добровольное распознавание без хранения исходного файла, редактируемый черновик и обязательное человеческое подтверждение перед созданием;
- «Приёмка» переименована в «Проверку системы» и объясняет, что это технический предрелизный контроль; жизненный путь HR строится только для явно выбранного сотрудника;
