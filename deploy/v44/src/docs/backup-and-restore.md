# Резервное копирование и восстановление

Текущий тестовый контур хранит единые карточки, задачи и процессы, чек-листы, согласования, уведомления, метаданные и версии документов, журнал действий и решения приёмки. До production необходимо доказать:

1. расписание резервных копий D1;
2. экспорт и проверку целостности;
3. восстановление в отдельный тестовый контур;
4. сверку количества записей и контрольных сумм;
5. измеренное RPO/RTO;
6. отдельную процедуру для документов R2 после его подключения.

Этап 18 разделяет две разные проверки:

- `DRILL-T-ARTIFACT-01` — сборка и неизменяемый артефакт приложения, пройдено;
- `DRILL-T-D1-RESTORE-01` — восстановление live D1 в отдельную базу, не выполнено.

Проверка артефакта не заменяет восстановление данных. Пока live restore drill не пройден с количеством записей, контрольными суммами и измеренными RPO/RTO, production readiness запрещена.
