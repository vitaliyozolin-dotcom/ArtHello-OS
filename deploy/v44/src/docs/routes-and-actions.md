# Маршруты и действия

Текущий интерфейс — один защищённый workspace-маршрут с клиентской навигацией; API-действия выполняются на сервере.

# Visual master-route · 2026-08-21

Новая системная навигация работает поверх сохранённых доменных API:

- `#home` — персональный дашборд по выбранной роли;
- `#<module>` — начало раздела с `pushState`, browser back и scroll restoration;
- логотип — `#home`;
- `Ctrl/Cmd + K` — командная палитра;
- global search — разделы, семьи, сотрудники, договоры, платежи, лиды, программы, события, подрядчики, оборудование, обращения и задачи;
- системный context bar — логический возврат, хлебные крошки, начало раздела, команды;
- mobile dock — главная, задачи, создание, поиск, разделы.

Самостоятельные маршруты, добавленные по мастер-промту:

- `#events`;
- `#contractors`;
- `#access`;
- `#assets`;
- `#quality`.

Все пять используют единый рабочий паттерн: KPI → фильтрованный реестр → карточка → связь → задача/история/источник.
