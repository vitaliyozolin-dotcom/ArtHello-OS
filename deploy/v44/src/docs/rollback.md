# Откат

Каждый checkpoint Sites является неизменяемой версией. Откат выполняется публикацией последней принятой версии без ручного изменения production-данных.

Для схемы D1 применяются только добавочные миграции. Разрушающее удаление полей запрещено без резервной копии, сверки и отдельного плана восстановления.

На этапе 18 проверены production build и аддитивная миграция `0018_strong_mojo.sql`. Это подтверждает откат приложения на предыдущий Sites checkpoint, но не подменяет отдельный D1 restore drill.
