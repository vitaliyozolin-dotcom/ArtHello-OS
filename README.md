# ArtHello OS

Private repository for the audited development of ArtHello OS.

## Project library

The versioned project library is available at [`docs/INDEX.md`](docs/INDEX.md).

It contains:

- governance and project boundaries;
- product scope and roadmap;
- Company OS entity model;
- ArtHello domain entities;
- sources of truth and integration rules;
- sales, service and knowledge-base specifications;
- decisions, QA gates and operational snapshots.

## Safety state

- Production and live-data gates remain closed.
- AlfaCRM and bank integrations are read-only until a separately approved gate.
- Real client channels and external AI actions are disabled.
- Sensitive data and secrets are not stored in project documentation.
