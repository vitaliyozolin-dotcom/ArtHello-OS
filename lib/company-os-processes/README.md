# Company OS Process Library

Рабочая библиотека стандартных процессов Company OS. Это не новые фундаментальные агенты: каждый процесс использует Memory, Intelligence, Competence Network, Execution и Evolution.

## Реализовано в v0.1

- Capacity & Enrollment Planner
- Receivables Orchestrator
- Growth Experiment Engine
- Founder Bottleneck Miner
- Assumption Reality Check

`selectProcesses(context)` подключает процессы по сигналам проекта. Если известная стоимость процесса выше ожидаемой пользы, библиотека возвращает пустой набор — это техническое ограничение против бюрократии.

## Сигналы

- `education-capacity`
- `receivables`
- `marketing-experiment`
- `founder-repeat`
- `financial-model`

## Следующая стадия

Подключить реальные входные/выходные адаптеры к Memory/Audit и провести по одному пилоту для каждого процесса. До этого пакет является рабочим ядром выбора и конфигурации процессов, но не считается полностью внедрённым бизнес-процессом.
